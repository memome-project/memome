Contribute

The corpus is community-maintained and evidence-gated. Anyone can contribute, dispute, or propose — but nothing enters without traceable evidence.

Submit evidence for a proposed entry

  1. Open a pull request citing the source. One Source ID = one identifiable evidentiary object — primary documents (FCC orders, CVEs, arXiv papers, vendor disclosures) over secondary coverage.
  2. Maintainers apply the promotion criteria (see the repo's docs/PROMOTION_CRITERIA.md) and respond within the SLA.
  3. Real, traceable cases only — no hypotheticals in the pilot corpus. New proposals land in proposed/ first, always.

Propose a new entry

New patterns land in proposed/, never directly in the core. Inclusion requires ≥2 of 5 operational tests: identifiable semantic or behavioral pattern; repeated transmission; adoption or behavioral effect; identifiable transmission mechanism; recurrence across hosts or contexts.

Dispute an entry

Contested classifications become assertions, not edit wars: whoever disputes first writes the assertion. If the same field is contested three or more times, the coding guide gains a concrete rule; if that can't fix it, it becomes a v0.3 schema candidate via the RFC process. Maintainers must respond with a written ruling within the published SLA.

RFC — schema and enum changes

  1. Propose via GitHub issue: rationale + ≥1 real use case.
  2. Comment window: 14 days (pilot) / 30 days (post-pilot).
  3. Vote: maintainer + board, simple majority, ≥2 distinct supporting contributors (not the author).
  4. Decision recorded: accepted → schema change + validator update; rejected → documented reason.
  5. Deprecation: enum values are never removed silently.

Ground rules

  • Mechanisms and observable patterns only — no ideology judgments.
  • Proposed mitigations are labeled proposed, never displayed as validated.
  • Run the validator before submitting.
  • Dual-use content is gated: high-exploitability payload content is redacted, and redaction is never pretended away.
During the pilot: contributions flow through the review rounds and the public comment period intake. See the comment-period section for what's open and how to file.
